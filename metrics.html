Editing

This hosted site is a viewer. You can update what visitors see (import a content pack, set a view password), but you cannot edit markdown or rebuild PDFs here.

To edit content, install and run a local copy of this app with POP_MODE=edit, rebuild PDFs on your machine, then use Build Render import pack locally and upload it below.
